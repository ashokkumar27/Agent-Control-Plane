# Roadmap

## v2 completed in this package

- YAML-first governance project layout
- Plain-language review command
- Readiness assessment command
- Local governance onboarding portal
- Developer-friendly `ControlPlaneProject.load()` API
- Developer-friendly `guarded_callable()` wrapper
- Fluent policy builder
- Intake templates for non-technical users
- Sample project and examples

## Next production milestones

1. Central API service with authentication.
2. Persistent registries and approvals in Postgres.
3. Policy versioning, review, and rollback.
4. Slack / Teams / Jira / ServiceNow approval integrations.
5. MCP governance gateway.
6. SIEM and OpenTelemetry integrations.
7. Admin dashboard with audit explorer.
8. DLP and tool-result redaction.
9. CI/CD deployment gates.
10. Immutable evidence store.
